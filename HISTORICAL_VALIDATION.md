# Historical validation: actual versus DET

Open **Historical validation** for three actual-versus-predicted graphs, zone/horizon/date controls, MAE/RMSE/R², exact-origin inspection and CSV/audit downloads. The active frozen DET fits only through June 2021 and selects settings using July–December 2021, then scores 2022–10 February 2023 after model selection is available.

The selected refined model is candidate 5, epoch 54. There are 3,129 paired records: 51/50/48 eligible dates for 1/2/4 native observation steps, approximately 8/16/32 days. Whole-lake curves apply the same origin-date zone weights to both actual and predicted values.
